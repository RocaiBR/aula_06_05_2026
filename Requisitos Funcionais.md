# Requisitos Funcionais (RF)

- RF01: O sistema deve permitir o cadastro de unidades de cinema (nome, endereço, capacidade).

- RF02: O sistema deve permitir o cadastro de filmes (título, gênero, diretor, elenco, duração).

- RF03: O sistema deve permitir o agendamento de sessões vinculando um filme a um cinema em um horário específico.

- RF04: O sistema deve permitir o registro diário do público de cada sessão.

- RF05: O sistema deve permitir a consulta do total de público (por sessão, por filme e por cinema).
